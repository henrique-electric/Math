What Is a Limit?

Before anything else, let us be clear about what we are doing. We want to give a precise, unambiguous meaning to the statement

limx→a f(x) = L

The naive reading is: "as x gets close to a, f(x) gets close to L." This is geometrically suggestive but logically useless. What does "close" mean? Close enough for what purpose? The genius of the ε-δ definition — due essentially to Cauchy and given its modern form by Weierstrass — is that it eliminates the word "close" entirely in favour of a precise logical game.

Spivak's Starting Point

Spivak opens his treatment of limits in Calculus with a confession: the definition will look formidable. His goal is not to make it feel easy but to make it feel necessary — to show that any attempt to say what a limit is leads inevitably to this definition and no other.

The ε-δ Definition

We say limx→a f(x) = L if the following holds:

Definition (Weierstrass, ~1861)

For every number ε > 0, there exists a number δ > 0 such that: for all x, if 0 < |x − a| < δ, then |f(x) − L| < ε.

In symbols:

∀ε > 0, ∃δ > 0 : 0 < |x − a| < δ  ⟹  |f(x) − L| < ε

Let us parse this with care.

The quantifier structure

The definition begins with ∀ε > 0 — "for every ε greater than zero." This means: no matter what positive ε an adversary hands you, you must be able to respond. The definition is an infinite challenge: it must work for ε = 1, for ε = 0.001, for ε = 10−100, and for every other positive number simultaneously.

Then comes ∃δ > 0 — "there exists a δ greater than zero." Your response to the ε-challenge is to produce a δ. This δ is allowed to depend on ε (and on a and on f). Typically, the smaller ε is, the smaller δ must be.

The condition 0 < |x − a| < δ

The left inequality 0 < |x − a| is crucial and is easy to overlook. It says x ≠ a. The limit is a statement about what f(x) does as x approaches a — the value f(a) is completely irrelevant. Indeed, f need not even be defined at a. The puncture 0 < is the formal expression of this.

The right inequality |x − a| < δ says x is within δ of a. Together, the condition defines the punctured δ-neighbourhood of a:

(a − δ, a) ∪ (a, a + δ)  =  {x : 0 < |x − a| < δ}

The conclusion |f(x) − L| < ε

For any x in the punctured δ-neighbourhood, f(x) must lie within ε of L — that is, in the interval (L − ε, L + ε). The entire statement is: you can force f(x) into any output window (L − ε, L + ε) by choosing x from a sufficiently small punctured input window around a.

Why strict inequalities? The strict inequality |f(x) − L| < ε (rather than ≤) is conventional but inessential — the two formulations are equivalent. Similarly for |x − a| < δ. Spivak uses strict inequalities throughout.

What the Definition Does Not Say

The definition does not say: "f(x) gets arbitrarily close to L." Getting close is not enough — the function must be able to be forced as close as desired. The word "every" in "for every ε" is doing all the work.

A Common Misconception

Students sometimes think limx→a f(x) = L means f(x) = L for x near a, or that x "reaches" a. Neither is true. The limit is purely about the behaviour of f near a, not at a. The function may behave wildly at a itself.

One-Sided Limits

Sometimes f behaves differently as x approaches a from the left versus from the right. The one-sided limit from the left is:

limx→a− f(x) = L  ⟺  ∀ε>0, ∃δ>0 : a−δ < x < a  ⟹  |f(x)−L| < ε

And from the right (replace a − δ < x < a with a < x < a + δ). The two-sided limit exists and equals L if and only if both one-sided limits exist and equal L.

Continuity as a Corollary

Once we have limits, continuity is almost free. We say f is continuous at a if:

limx→a f(x) = f(a)

Three things must hold: f must be defined at a; the limit must exist; and they must agree. This is Spivak's Chapter 5 — continuity is the limit definition applied to the case x = a with no puncture needed, since we require the value to match.

The Challenge-Response Game

The deepest way to understand the ε-δ definition is as a game between two players. Call them the Challenger and the Defender.

The Challenger's job is to demand precision: they name an output tolerance ε > 0. Think of ε as the width of a horizontal band around L on the y-axis. The Challenger is saying: "I require that f(x) land within this band whenever x is close enough to a."

The Defender's job is to find a corresponding input restriction δ > 0 — a horizontal band around a on the x-axis — such that any x inside that δ-band (but not equal to a) maps to an f(x) inside the ε-band.

The Definition as a Game

limx→a f(x) = L means: the Defender always wins. No matter how small the Challenger makes ε, the Defender can always find a δ that works. If there exists even one ε for which no δ works, the limit is not L.

Why the Challenger moves first

The order of quantifiers is everything. ∀ε, ∃δ means ε comes first — the Challenger names ε, then the Defender responds with δ. Reversing this to ∃δ, ∀ε would mean δ is chosen first, independently of ε. That would be a much stronger (and wrong) statement: a single δ that works for all ε simultaneously.

The dependence of δ on ε is not a bug — it is the entire point. As the Challenger tightens the band (smaller ε), the Defender must tighten the restriction (smaller δ). The limit exists when this mutual tightening can continue indefinitely without failure.

Geometric picture

Draw the graph of f. Around the point (a, L) on the graph, draw a horizontal strip of width 2ε (from y = L − ε to y = L + ε). Now draw a vertical strip of width 2δ (from x = a − δ to x = a + δ). The ε-δ condition says: the part of the graph inside the vertical strip must lie entirely inside the horizontal strip — except possibly at x = a itself, which is punched out.

Challenger's move
ε — output tolerance

A horizontal band of half-width ε around L on the y-axis. Any point outside this band is unacceptable. The smaller ε is, the tighter the demand.

Defender's response
δ — input restriction

A punctured interval of half-width δ around a on the x-axis. Any x in this punctured window must map into the ε-band. The Defender wins if the graph stays inside.

Why "Punctured"?

The hole at x = a is essential. Consider f defined as f(x) = x² for x ≠ 2 and f(2) = 17. The limit as x → 2 is still 4, not 17. The value f(2) = 17 is invisible to the limit. This is not a quirk — it is the entire point of the definition. Limits describe tendencies, not values. A function can tend toward a value it never actually reaches, or a value that contradicts its definition at that point.

Spivak's example (Ch. 5): The function f(x) = sin(1/x) oscillates infinitely rapidly near 0. The limit as x → 0 does not exist — there is no L for which a δ can be found for all small ε. This is invisible from the formula but revealed by the definition.

Limits That Do Not Exist

The ε-δ framework also clarifies when a limit fails to exist. There are three ways:

1. Oscillation. Like sin(1/x) near 0. The function visits every value in [−1, 1] in every punctured neighbourhood of 0. No single L can be within ε of all of them for small ε.

2. Jump discontinuity. Like f(x) = 0 for x < 0, f(x) = 1 for x ≥ 0 near a = 0. The left and right limits exist (0 and 1 respectively) but they disagree. The two-sided limit does not exist.

3. Blow-up. Like 1/x near 0. f(x) becomes unbounded; no finite L can work.

Negating the Definition

To prove limx→a f(x) ≠ L, you must exhibit a specific ε > 0 for which no δ works. That is: find ε such that for every δ > 0, there exists an x with 0 < |x − a| < δ but |f(x) − L| ≥ ε. One ε suffices — you don't need to handle all of them.

The Algebraic Strategy: Finding δ from ε

In practice, to prove limx→a f(x) = L, you must show how to construct δ given ε. The strategy, as Spivak consistently demonstrates, is:

Start with the conclusion you need: |f(x) − L| < ε. Manipulate this algebraically to find what |x − a| must be bounded by. This gives you a formula for δ in terms of ε. Then verify that this δ works — that is, trace the logic in reverse.

There is always freedom in choosing δ: any smaller δ also works, so you may impose additional restrictions (like δ ≤ 1) to simplify the algebra. Spivak calls this "the δ-trick" — choosing δ as the minimum of several bounds.

The Spivak Pattern

Every ε-δ proof in Spivak follows the same skeleton: (1) do scratch work to find a candidate δ; (2) write the formal proof starting with "Let ε > 0 be given; choose δ = …"; (3) verify that the choice works by deriving |f(x) − L| < ε. The scratch work is not part of the proof — only the verification is.

Connection to Derivatives

The derivative is itself a limit. The definition f′(a) = limh→0 [f(a+h) − f(a)] / h is an ε-δ statement with a = 0, the function g(h) = [f(a+h)−f(a)]/h, and L = f′(a). All the theorems about limits — linearity, products, quotients, composition — apply directly to derivatives, because derivatives are limits. The ε-δ machinery, built once, propagates through all of calculus.

A complete ε-δ proof: show that limx→2 (3x − 1) = 5.

1

State what we must prove

We claim that limx→2 (3x − 1) = 5. According to the ε-δ definition, we must show:

∀ε > 0, ∃δ > 0 : 0 < |x − 2| < δ  ⟹  |(3x−1) − 5| < ε

We do scratch work first to discover what δ should be, then write the formal proof.

2

Scratch work — simplify the conclusion

We want to control |(3x − 1) − 5|. Simplify:

|(3x − 1) − 5| = |3x − 6| = 3|x − 2|

We need this to be less than ε. So we need:

3|x − 2| < ε  ⟺  |x − 2| < ε/3
Candidate: choose δ = ε/3. If we restrict x so that |x − 2| < δ = ε/3, then |(3x−1) − 5| = 3|x−2| < 3 · (ε/3) = ε. ✓
3

Write the formal proof

Now we write the proof in the proper order — no scratch work visible, just the verified argument:

Let ε > 0 be given. Choose δ = ε/3.

Then δ > 0 (since ε > 0). Suppose 0 < |x − 2| < δ. Then:

|(3x − 1) − 5| = |3x − 6| = 3|x − 2| < 3δ = 3 · (ε/3) = ε.
Conclusion: |(3x − 1) − 5| < ε. Since ε was arbitrary, the limit is proved. □
4

Understanding what we just did

The key move was algebraic: we simplified |f(x) − L| until it had the form C · |x − a| for some constant C. Then δ = ε/C works. This pattern applies whenever f is a linear function.

Why ε/3 specifically? Because the "slope" of f(x) = 3x − 1 is 3. The derivative f′(2) = 3 tells us how much output change per unit of input change. To get output change < ε, we need input change < ε/3. The ε-δ machinery is secretly encoding linearisation — a preview of differentiation.
5

A harder case: limx→2 x² = 4

Now f is nonlinear. Scratch work: we need |x² − 4| < ε. Factor:

|x² − 4| = |x + 2| · |x − 2|

The |x + 2| factor depends on x — we cannot directly set δ = ε / |x + 2|. We must bound |x + 2| first.

The δ-trick: We are free to impose δ ≤ 1 as an additional constraint. If |x − 2| < 1, then 1 < x < 3, so 3 < x + 2 < 5, hence |x + 2| < 5. Therefore: |x² − 4| = |x + 2| · |x − 2| < 5 · |x − 2|.

Now we need 5|x − 2| < ε, so |x − 2| < ε/5. Choose:

δ = min(1, ε/5)
Why the minimum? We need both constraints to hold simultaneously: |x − 2| < 1 (to bound |x + 2|) AND |x − 2| < ε/5 (to complete the inequality). The minimum satisfies both.
6

Formal proof for x²

Let ε > 0. Choose δ = min(1, ε/5). Suppose 0 < |x − 2| < δ. Then:

Since δ ≤ 1, we have |x − 2| < 1, so x ∈ (1, 3), hence |x + 2| < 5.

Therefore: |x² − 4| = |x+2| · |x−2| < 5 · δ ≤ 5 · (ε/5) = ε. □
Note on tightness: The δ we chose (min(1, ε/5)) is not the largest possible δ that works — it is merely sufficient. A tighter bound exists (the exact largest δ can be computed geometrically), but for the proof, any valid δ is enough.
7

The general method

The pattern from these examples is:

|f(x) − L| = (bound on other factors) · |x − a| < C · δ

We choose δ = ε/C (possibly further restricted to ≤ 1 to establish the bound C). Whenever f is a polynomial, rational function near a non-zero denominator, or a composition of nice functions, this strategy works and gives an explicit δ in terms of ε.

The key insight from Spivak: In every single ε-δ proof you will ever write, the structure is the same. The creativity lies only in how you bound |f(x) − L| in terms of |x − a|. Once you have that inequality, the rest is mechanical.

Limit Does Not Exist

Jump discontinuity Disproof
limx→0 sgn(x) does not exist
Left limit: limx→0⁻ sgn(x) = −1
Right limit: limx→0⁺ sgn(x) = +1
ε-δ disproof: Take ε = 1. For any δ > 0, pick x₁ = −δ/2 and x₂ = δ/2. Both are in (−δ, δ)\{0} but sgn(x₁) = −1 and sgn(x₂) = 1. These differ by 2 > 2ε = 2, so no single L can satisfy |sgn(xᵢ) − L| < 1 for both.
No L exists — the two-sided limit fails  ✗
Wild oscillation Disproof
limx→0 sin(1/x) does not exist
Key idea: In any interval (−δ, δ)\{0}, sin(1/x) takes all values in [−1, 1].
Proof: Take ε = 1/2. For any claimed L and any δ, pick xₙ = 1/(nπ/2) for large enough n so that xₙ ∈ (0,δ). Then sin(1/xₙ) alternates between −1, 0, 1. No matter what L is, at least one of these values satisfies |sin(1/xₙ) − L| ≥ 1/2 = ε.
No L exists — the oscillation prevents any δ from working  ✗
ε (epsilon)
A positive real number representing the output tolerance — how close f(x) must be to the limit L. In the game interpretation, ε is the Challenger's move.
Always quantified universally: "for every ε > 0." The definition must work for arbitrarily small ε.
δ (delta)
A positive real number representing the input restriction — how close x must be to a. In the game interpretation, δ is the Defender's response to ε.
δ is allowed to depend on ε (and on a and f). Smaller ε typically requires smaller δ. Any valid δ suffices; the largest valid δ is not required.
Punctured neighbourhood
The set {x : 0 < |x − a| < δ} = (a−δ, a) ∪ (a, a+δ). The point a itself is excluded (punctured). The limit is defined entirely in terms of behaviour in these punctured neighbourhoods.
Also called a "deleted neighbourhood." The condition 0 < |x − a| is what does the puncturing — it excludes x = a from consideration.
Quantifier order
The structure ∀ε, ∃δ means: ε is chosen first (by the adversary), then δ responds. Reversing to ∃δ, ∀ε would mean a single δ works for all ε — a much stronger and wrong statement.
The distinction between ∀∃ and ∃∀ is one of the most important logical distinctions in mathematics. The order of quantifiers completely changes the meaning.
One-sided limit
limx→a⁻ f(x) = L (from the left): restricts the punctured neighbourhood to (a−δ, a). From the right: (a, a+δ). The two-sided limit exists iff both one-sided limits agree.
Continuity at a
f is continuous at a if limx→a f(x) = f(a). Three conditions: (1) f(a) is defined; (2) the limit exists; (3) they are equal. Equivalently: ∀ε>0, ∃δ>0 : |x−a|<δ ⟹ |f(x)−f(a)|<ε (no puncture needed, since x=a is trivially fine).
Note the unpunctured condition |x − a| < δ (no 0 < required). This is because we explicitly include x = a and require f(a) to match.
The δ-trick
The technique of choosing δ = min(1, ε/C) (or similar) to simultaneously impose a bound on the non-|x−a| factors and satisfy the final ε requirement. Ubiquitous in ε-δ proofs for nonlinear functions.
The choice δ ≤ 1 is conventional; any fixed bound works (δ ≤ 2, δ ≤ 1/2, etc.). The constant C changes accordingly. Choosing 1 is simply the cleanest.
Limit at infinity
limx→∞ f(x) = L means: ∀ε>0, ∃M : x>M ⟹ |f(x)−L|<ε. Here δ is replaced by M (a large x threshold). The ε-challenge is the same; the response is a large-x cutoff rather than a small interval.
Infinite limit
limx→a f(x) = ∞ means: ∀M>0, ∃δ>0 : 0<|x−a|<δ ⟹ f(x)>M. The roles are reversed: M plays the role of the Challenger's "demand" (f(x) must be large), and δ is the Defender's response.
This is not a limit in the strict sense (∞ is not a real number), but Spivak treats it carefully as a definition in its own right.
Squeeze theorem
If g(x) ≤ f(x) ≤ h(x) near a, and lim g = lim h = L, then lim f = L. The ε-δ proof: given ε, find δ₁ for g and δ₂ for h, then choose δ = min(δ₁, δ₂).
The canonical application: limx→0 x·sin(1/x) = 0, since −|x| ≤ x·sin(1/x) ≤ |x| and lim |x| = 0.
